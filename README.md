# 优学院作业助手
> 针对DGUT版优学院（lms.dgut.edu.cn）的作业查询工具，GUI图形界面，一键查看未完成作业，支持查看作业详情、下载附件图片、导出作业列表。

## ✨ 功能特性
1. 账号密码登录，自动获取Token，也可手动填入Token
2. 批量扫描待完成作业（未提交 / 未互评 / 需重写）
3. 作业列表自动按截止时间排序
4. 双击作业行查看完整作业文字详情
5. 下载作业内附件、内嵌图片到本地文件夹
6. 保存作业详情为文本文件
7. 扫描完成自动导出作业列表为Excel（需`openpyxl`）
8. 鼠标悬浮提示Tooltip，操作指引提示

## ⚠️ 重要提示（必读）
1. **默认只查询最新20门课程**，代码类`HomeworkChecker`中常量`PAGE_SIZE = 20`，如果你的课程总数大于20，自行修改这个数值调大，才能读取全部课程。
2. **Token 在有效期内可以重复使用，无需重复登录**，程序退出时可选择将账号密码、Token保存到本地`config.json`，下次打开自动加载。
3. 扫描作业时，**留意控制台/终端输出**，部分课程可能因为网络超时、接口异常跳过读取，终端会打印`获取课程「xxx」作业失败，已跳过`，代表该课程作业没有被扫描出来。
4. 仅用于个人学习，请勿高频调用接口，避免账号受限。

## 📦 依赖安装
```bash
pip install requests openpyxl
```
- `requests`：网络请求，必须安装
- `openpyxl`：用于导出Excel作业列表；不安装程序可正常运行，只是无法导出xlsx。

## 🚀 使用步骤
1. 安装依赖，运行脚本 `python homework-assistant.py`
2. 输入平台账号密码，点击【登录】，自动填充Token；也可以直接粘贴有效Token
3. 点击【扫描作业】，程序读取课程与待完成作业
4. 扫描结束后表格展示待完成作业，按截止时间升序排列
5. **双击表格中的一行作业**，加载作业详情，文本框展示作业描述、图片&附件清单
6. 按钮功能：
    - `保存作业详情`：将作业要求保存为txt文本，存到课程命名文件夹
    - `下载附件&图片`：下载该作业全部图片、附件，保存至本地课程文件夹
7. 退出程序时可在弹窗中选择保存账号、Token到`config.json`。

## 📁 文件说明
```
├── homework-assistant.py              # 主程序
├── config.json         # 配置文件（程序运行后生成，保存账号密码token）
├── 作业列表_xxx.xlsx   # 扫描完成自动导出的作业表格
├── 【课程名】/          # 自动生成，存放下载附件、图片、作业详情txt
```

## 🔧 参数修改
修改扫描课程数量：打开源码，找到 `HomeworkChecker` 类：
```python
class HomeworkChecker:
    """作业扫描核心逻辑类"""
    PAGE_SIZE = 20    # 在这里修改，调大可以读取更多课程
```

## 🐛 常见问题
1. **Token无效/过期**：扫描提示401/403，重新账号密码登录获取新Token。
2. Excel导出不可用：执行`pip install openpyxl`。
3. 自行填入Token无法查看作业详情：缺少参数`userid`，需往`config.json`填入该参数值。
4. 文件保存失败：路径存在非法字符，程序会自动替换非法符号。
5. 本程序只能解析小组作业、个人作业的内容。其他类型作业能扫描到，但无法显示具体内容。
